# 🎓 Campus Connect

Campus Connect is a full-stack MERN application designed to simplify college event and club management. It provides role-based dashboards for students, club coordinators, and administrators to manage registrations, attendance, announcements, and analytics from a single platform.

## ✨ Features

### Student
- Register & Login
- Browse Events
- Register for Events
- View Registered Events
- QR Code Ticket
- Notifications
- Download Certificates

### Club Coordinator
- Create/Edit/Delete Events
- Manage Registrations
- Mark Attendance
- Upload Certificates
- Event Analytics

### Admin
- User Management
- Club Management
- Event Management
- Dashboard & Reports
